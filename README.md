# Terraform AWS EC2 and S3 Project

## Project Overview

This project demonstrates how to provision AWS resources using Terraform.

## AWS Resources

- EC2 Instance
- S3 Bucket

## Technologies Used

- AWS
- Terraform
- Git
- GitHub

## Project Files

- main.tf - AWS provider, EC2 and S3 configuration
- variables.tf - Terraform variables
- outputs.tf - Terraform outputs
- README.md - Project documentation
